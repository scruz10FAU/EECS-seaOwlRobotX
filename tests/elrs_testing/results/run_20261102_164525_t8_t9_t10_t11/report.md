## Caveats
- Latencies subtract timestamps from three clocks (UAV, Windows, WSL). Any offset between them is baked into the absolute values; a negative hop is the visible symptom. Sync clocks before trusting absolute latency.
- Test1's router log stored raw serial chunks: beacon frames were recovered by CRC-checking the byte stream, but per-type link statistics are unavailable and its bytes/s counts raw serial bytes, not parsed frames.
- Test5 has no bridge log, so its radio hop is measured from the ROS publish time.
- Rows from earlier runs appended to the same log (seen in test4 and test7 bridge logs) are dropped using the publish time window.
